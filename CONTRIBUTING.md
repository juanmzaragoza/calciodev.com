# Contributing to Astro SEO Theme

Thank you for your interest in contributing to Astro SEO Theme! We welcome contributions from everyone.

## How to Contribute

### 1. Fork & Clone

1. Fork the repository on GitHub.
2. Clone your fork locally: `git clone https://github.com/YOUR_USERNAME/astro-seo-theme.git`
3. Navigate into the directory: `cd astro-seo-theme`

### 2. Setup

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`

### 3. Make Changes

1. Create a new branch for your feature or bugfix: `git checkout -b feature/your-feature-name`
2. Make your changes in the code.
3. Verify your changes don't break the build: `npm run build`

### 4. Commit and Push

1. Commit your changes with descriptive messages: `git commit -m "feat: add amazing new feature"`
2. Push to your fork: `git push origin feature/your-feature-name`

### 5. Create a Pull Request

1. Go to the original repository on GitHub.
2. Click "Compare & pull request".
3. Fill out the PR template.

## Code Style

- We use Tailwind CSS v4 for all styling. Please do not introduce new CSS frameworks or runtime-heavy CSS-in-JS libraries.
- Keep JavaScript to an absolute minimum. Rely on Astro's static generation and CSS for interactivity whenever possible.
