## Context

IVEE, a veterinary company, held years of clinical histories — but they were locked inside PDFs exported from several different systems, in formats nobody could analyze at scale.

## The problem

The information existed, but it was unusable: every source system produced a differently-shaped PDF, and there was no way to ask questions across all of them.

## What we did

- Built a **Cloud Function that triggers on every PDF upload**, so new documents are processed automatically.
- Wrote a **modular parser with a format-specific module per source system**, so each PDF layout is handled correctly.
- Loaded the extracted, structured data into **BigQuery** and built **dashboards** on top of it.

## Result

Clinical histories that no one could analyze became structured data IVEE can actually query and report on — the foundation for a two-year collaboration.

## Stack

Google Cloud Functions · Modular PDF parsing · BigQuery · Dashboards
