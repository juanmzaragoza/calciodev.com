# Primeros pasos con Astro SEO Theme

Bienvenido a **Astro SEO Theme** — la plantilla definitiva de código abierto de Astro construida específicamente para sitios web de marketing B2B y SaaS. Esta guía te acompañará a través de la instalación, configuración y tu primer despliegue.

## ¿Qué hace diferente a este Theme?

A diferencia de otros themes de Astro que tratan el SEO como algo secundario, este theme fue diseñado desde cero apoyándose en tres pilares:

1. **SEO Técnico**: JSON-LD automático, etiquetas meta dinámicas, sitemap, URLs canónicas y soporte hreflang.
2. **GEO (Generative Engine Optimization)**: Contenido estructurado que los motores de búsqueda de IA pueden analizar, citar y recomendar.
3. **AEO (Answer Engine Optimization)**: Formato de contenido optimizado para Fragmentos Destacados y resultados de cero clics.

## Inicio Rápido

Instala el theme y comienza a desarrollar en menos de un minuto:

```bash
# Clona el repositorio
git clone https://github.com/druedaro/astro-seo-theme.git
cd astro-seo-theme

# Instala las dependencias
npm install

# Inicia el servidor de desarrollo
npm run dev
```

Tu sitio estará funcionando en `http://localhost:4321`.

## ¿Qué incluye?

- **Modo Oscuro** con prevención de FOUC
- **Colecciones de Contenido** con esquemas de TypeScript
- **Tailwind CSS v4** con un sistema de diseño personalizado
- **React Islands** para componentes interactivos
- **Soporte MDX** para la creación de contenido enriquecido
- **Feed RSS** generado automáticamente
- **Sitemap** generado automáticamente

## Próximos Pasos

Explora el theme, personaliza el sistema de diseño en `src/styles/global.css` y comienza a crear tus páginas de marketing SaaS.
